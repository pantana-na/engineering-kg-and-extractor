## 2. Hybrid Trigger Architecture: `AGENTS.md` + 3 Consolidated Rules + `ai-sdlc` Master Hub Skill

To enforce strict lifecycle compliance while minimizing context token consumption across turns, this repository uses a 3-layer customization design:
1. **Executive Router ([`AGENTS.md`](../../../../AGENTS.md)):** A concise workspace root index that routes the agent to the `ai-sdlc` master hub skill, the 3 consolidated rules (Rules 1–13), and the 4 companion skills without duplicating detailed text.
2. **Always-On Lifecycle, SDD & RCA Rule ([`_agents/rules/ai_sdlc_and_sdd_standards.md`](../../../rules/ai_sdlc_and_sdd_standards.md) — `trigger: always_on`, Rule 13):**
   - Unconditionally active on every turn so the agent never skips **Phase 1 (Inception)**, **Phase 2 (SDD Execution)**, or **Phase 3 (Operation)**, enforces Google Cloud WAF & SAIF Supreme Precedence, always asks clarification questions (`ask_question`) on unknowns, enforces interactive phase gates, and executes the **4-Step RCA Protocol (Rule 13)** on any failing test/eval.
3. **Domain-Specific Rules (`trigger: model_decision`) & On-Demand Companion Skills:**
   - [`google_adk_and_agent_runtime.md`](../../../rules/google_adk_and_agent_runtime.md) (**Rules 11–12**) and [`devops_security_and_quality_standards.md`](../../../rules/devops_security_and_quality_standards.md) (**Rules 1–10**) use `trigger: model_decision` with rich descriptions so they load automatically when working on ADK agents (`agent_runtime`) or Cloud Run/DevSecOps (`cloud_run`), saving context tokens when not needed.
