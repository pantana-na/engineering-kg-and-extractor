3-Phase AI-SDLC & Spec-Driven Development (SDD) Architecture

Step-by-Step Lifecycle Topology • Separated Brownfield Track (Track A: Legacy .NET/3-Tier & Track B: Undocumented Cloud-Native) vs. Greenfield Track • Skills, Tools & Interactive Phase Gates

Brownfield Track (Track A & Track B)

  • • Track A (Legacy 3-Tier / .NET): Scans *.sln, *.aspx, WCF *.svc, Web.config, and extracts hidden business logic from SQL Stored Procedures (sp_* / usp_*) and Triggers.
  • • Track B (Undocumented Cloud-Native): Reverse-engineers implicit route contracts, reconciles type drift, and flags coupled LLM agents or regex intent routers.
  • • Safety Net First (Step 2.0B): Codifies specs/baseline/*.md and locks in Golden Master Characterization Tests + Generative PBTs before touching production code.
  • • Modernization Cutover: Supports Strangler Fig API Facade, Full Dual-Runtime Re-Architecture, or In-Place Hardening.

Greenfield Track (Cloud-Native & ADK)

  • • Direct Intent-to-Spec Framing: Elicits business intent, personas, measurable goals/non-goals, and systems of record via ask_question.
  • • Dual-Runtime Separation: Strictly decouples ADK reasoning agents (agent_runtime) from React/Vite UI & FastAPI/Express streaming proxies (cloud_run).
  • • Step 2.0G Baseline Bypass: Bypasses legacy reverse-engineering and authors specs/features/SPEC-YYYYMMDD-*.md directly from sdd-template.md.
  • • Test-First Execution: Every implementation step requires Deterministic Unit Tests, Generative PBTs (hypothesis/fast-check), and live agents-cli eval.

Skills, Tools & Governance Gates

  • • 4 Specialized Skills: ai-sdlc (master orchestrator), architecture-diagram (visual topology), gcp-cost-estimator (live Billing API BoM), and codemender (SAST find/verify/fix).
  • • Interactive Gates (ask_question): Enforces Zero Silent Assumptions and explicit user sign-off at Gate 1, Sub-Gate 2A (Pre-Code), RCA Sub-Gate, and Gate 2.
  • • Mandatory 4-Step RCA: Prohibits quick fixes, mockup fallbacks, or regex patches; requires deep RCA and user selection of sustainable architectural fixes.
  • • Automated Gate Validator: validate_sdlc_gate.py scaffolds workspaces (--init) and audits phase readiness (--phase inception|execution|operation).
