## Skill Operating Guidelines

1. **Supreme Precedence of Google Cloud WAF & Google SAIF (`gcp-well-architected-saif`):** All solution designs, architectures, specifications, and deployments must adhere to [`gcp_well_architected_saif/SKILL.md`](./gcp_well_architected_saif/SKILL.md). Whenever any legacy rule or heuristic conflicts with the Google Cloud Well-Architected Framework or Google Secure AI Framework, WAF and SAIF take strict precedence.
2. **Master Lifecycle Orchestration & Workspace Scaffolding (`ai-sdlc`):** All feature development, architecture design, refactoring, and deployments are guided by [`ai_sdlc/SKILL.md`](./ai_sdlc/SKILL.md). When activated, `ai-sdlc` runs `python3 _agents/skills/ai_sdlc/scripts/validate_sdlc_gate.py --init` to scaffold `specs/` and `docs/` into the project root from [`ai_sdlc/examples/specs/`](./ai_sdlc/examples/specs/) and [`ai_sdlc/examples/docs/`](./ai_sdlc/examples/docs/).
3. **Artifact Destination:** All operational reports, WAF/SAIF reviews, security assessments, cost models, and standalone diagrams generated by operational skills are saved to the project root's `docs/` directory, while SDD specifications and progress reports reside in `specs/`.
4. **Strict Live Pricing (Zero Caching):** The `gcp-cost-estimator` skill queries rates strictly from the live Google Cloud Billing API or official live pricing pages. No hardcoded or cached prices are permitted.
5. **Interactive Parameter Elicitation:** Agents must ask the user for all necessary requirements, sizing parameters, and workload variables via `ask_question` without making silent assumptions.
6. **User Confirmation for Phase Gates & Security Remediations:** Both the `ai-sdlc` skill (at every phase transition) and the `codemender` skill (before verifying/applying patches) require explicit user approval.
