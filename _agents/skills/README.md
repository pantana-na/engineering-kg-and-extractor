## Skill Operating Guidelines

1. **Master Lifecycle Orchestration & Workspace Scaffolding (`ai-sdlc`):** All feature development, architecture design, refactoring, and deployments are guided by [`ai_sdlc/SKILL.md`](./ai_sdlc/SKILL.md). When activated, `ai-sdlc` runs `python3 _agents/skills/ai_sdlc/scripts/validate_sdlc_gate.py --init` to scaffold `specs/` and `docs/` into the project root from [`ai_sdlc/examples/specs/`](./ai_sdlc/examples/specs/) and [`ai_sdlc/examples/docs/`](./ai_sdlc/examples/docs/).
2. **Artifact Destination:** All operational reports, security assessments, cost models, and standalone diagrams generated by operational skills are saved to the project root's `docs/` directory, while SDD specifications and progress reports reside in `specs/`.
3. **Strict Live Pricing (Zero Caching):** The `gcp_cost_estimator` skill queries rates strictly from the live Google Cloud Billing API or official live pricing pages. No hardcoded or cached prices are permitted.
4. **Interactive Parameter Elicitation:** Agents must ask the user for all necessary requirements, sizing parameters, and workload variables via `ask_question` without making silent assumptions.
5. **User Confirmation for Phase Gates & Security Remediations:** Both the `ai-sdlc` skill (at every phase transition) and the `codemender` skill (before verifying/applying patches) require explicit user approval.
